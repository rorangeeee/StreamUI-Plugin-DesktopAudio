# StreamUI-Plugin-DesktopAudio

Independent source plugin for [StreamUICore](https://github.com/rorangeeee/StreamUICore). Requires Windows x64, .NET 10 SDK and StreamUI Contracts SDK major 1.

Clone this repository to '<Core>/plugins/desktop-audio'. Build Core first, then run:

~~~powershell
powershell.exe -NoProfile -File build.ps1 -SdkPath '<Core>/sdk/native'
~~~

The SDK is generated by 'npm run sdk:build' or 'npm run host:package' in Core. This project references only the versioned SDK assembly; it has no dependency on the Core source checkout layout. The resulting DLL and dependency file remain beside 'plugin.json'.

The plugin is loaded only after explicitly enabling it or applying a preset that requires it. It runs with the Host user's native permissions.

## Source repository and editing

Track the C# source, project, build.ps1, NuGet.Config, manifest and settings page. DLLs, deps.json, bin, obj and release files are local build outputs and must stay ignored. Core's `docs/REPOSITORIES.md` defines the shared repository convention; run `npm run extensions:check -- <repository>` from Core to check it.

Core loads this installed repository directly. Exit Core before updating or rebuilding native DLLs, preserve personal source changes with Git, then build and restart Core. Existing plugin settings and plugin-data stay in the Core data directory. Legacy plugin copies in that directory are left untouched; select the intended working directory with `--plugins-dir` if needed.

The plugin's device, channel and gain controls save and apply automatically. Valid field edits use SDK field PATCH and `createAutoSave`, preserving unrelated settings. The settings page requires an updated Core build with browser SDK 2 (Core 0.5).
